# Matematik Tahun 6 - Set 2

Set latihan baharu dengan konsep, tahap persekolahan, format dan agihan markah yang sama seperti Set 1. Soalan, nombor, konteks, arah perubahan zon masa serta tiga rajah diganti. Set 1 tidak dipadam atau digantikan.

- A: 13 soalan / 26 markah.
- B: 2 soalan berbahagian / 24 markah.
- Jumlah: 50 markah / 75 minit.
- Lapan unit Tahun 6: nombor 6, pecahan/perpuluhan/peratus 7, wang 6, masa 6, ukuran 6, ruang 6, koordinat/nisbah/kadaran 7, data/kebolehjadian 6.

Kertas: `dist/matematik-set2.html`. Bank: `dist/questions-matematik-set2.js`. Penjana: `docs/create_math_set2.py`. Metadata markah: `docs/math-set2-coverage.json`.

## Kandungan

A1-A2: pecahan juta dan anu; A3-A4: bahagi pecahan serta darab perpuluhan; A5-A6: diskaun dan dividen; A7-A8: zon masa termasuk tarikh hari sebelumnya; A9: perkaitan panjang dan jisim; A10-A11: jejari dan sudut oktagon; A12: jarak mencancang berskala; A13: sektor carta pai 45 darjah.

B1: jumlah buku, 150% pengunjung, untung selepas rebat, waktu ketibaan dan nisbah lencana. B2: jisim jus, bilangan botol, sudut pusat, kadaran harga buku, carta pai dan peristiwa pasti.

## Pemarkahan

Polisi yang sama seperti Set 1: jawapan akhir betul mendapat markah penuh cadangan walaupun jalan kerja kosong. Sistem tidak menilai kaedah pengiraan secara automatik. Jawapan salah bermula dengan 0 cadangan; ibu bapa boleh memberi markah separa bagi kaedah yang betul berdasarkan skema. Sebab kebolehjadian menerima cadangan kata kunci dan perlu disemak manusia. Gred kekal gred latihan laman.
